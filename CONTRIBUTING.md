# Contributing to KESE

Contributions of every kind are welcome: code, bug reports, test boards,
documentation and research.

KESE is licensed under the PolyForm Noncommercial License 1.0.0, and its
copyright holder, RolandThsive, also offers separate commercial licenses (see
[COMMERCIAL.md](COMMERCIAL.md)). So that every part of KESE can be offered under
both, code, documentation and other material are accepted only under the
agreement below. Bug reports and ideas do not need it.

## How to agree

Check the Contributor License Agreement box in the pull request description.
Every person who authored a commit in the pull request must check it, or say in
a comment on the pull request: "I agree to the KESE Contributor License
Agreement." A pull request is not merged until this is done.
