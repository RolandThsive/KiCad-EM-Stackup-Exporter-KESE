"""
Dual_Board_Parameters.py  -  the one stator board and the one rotor disc that both coil sets share.

Units: millimetres, degrees, hertz unless a name says otherwise.
Nothing in this file is computed - edit values only.

The names are the Single Coil Set Generator's own (Board_Parameters.py, Rotor_Parameters.py) wherever the meaning is the
same, so the wiki's Parameter Reference applies.  What each coil set has for itself (its excitation frequency, its
RX band and fingers, its TX ring, its rotor ring, its IC) is in the Dual_RX1 / RX2, TX1 / TX2, Rotor1 / Rotor2 and
IC1 / IC2 files.  A set file may also give its own value for a few values of this file (its vias and clearance in
Dual_RX<k>, TX_AC_RESISTANCE_FACTOR in Dual_TX<k>, TANK_CAP_SERIES in Dual_IC<k>); the value here is the one used
where it does not.
"""

#   "strict" : every such warning is an error; nothing is written.

CENTER_Y_MM  = 100.0

# =============================================================================
# STATOR BOARD
# =============================================================================
# PCB_LAYERS = copper layers of the stator: 4 (1 = Top, 2 = Inner 1, 3 = Inner 2, 4 = Bottom; each set's RX on
# RX_LAYER_A / B and TX on TX_LAYER_A / B) or 2 (Top and Bottom: each set's RX rising edges on
# RX_RISING_EDGE_LAYER, its TX turns on both).  Four layers are the usual dual board: two layers leave no layer
# free for set 1's leads to cross set 2 (the checker warns).
PCB_LAYERS = 4

# Via / copper-to-copper rules the generator must respect when it places vias.  Through vias go
# through every layer, so a via of one set is checked against the copper of the other set on every layer.
# A set may have its own: VIA_DIAMETER_MM, VIA_DRILL_MM, VIA_TYPE and MIN_CLEARANCE_MM in Dual_RX1 / RX2
# (None there = these values).  Between the two sets the larger MIN_CLEARANCE_MM applies.
VIA_DIAMETER_MM   = 0.6             # (the Single Coil Set Generator's example uses 0.8 / 0.4; 0.6 / 0.3 leaves room in
VIA_DRILL_MM      = 0.3             #  the inner set's tight TX ring)
MIN_CLEARANCE_MM  = 0.2
# VIA_TYPE: "through" (plated holes through the board) or "blind" (every via written as a blind via
# between the two layers it joins: the RX layers of its set, or the TX layers / the TX layer and the layer of the
# inner tail).  Common fabs laser-drill blind vias only between an outer layer and its neighbour (Top + Inner 1,
# Inner 2 + Bottom) and at most about 0.15 mm wide, so set the via sizes above to match; the checker warns about a
# pair that skips a layer and about a drill wider than that.  The clearance checks treat every via as a through via.
VIA_TYPE          = "through"

# ---- board edges (Edge.Cuts circles) and the gap between the sets ----------
# From the centre out, the stator is:
#     bore | RX1 band | TX1 ring | TRACK_GAP_MM | RX2 band | TX2 ring | outline
# You give what you know and the generator places the rest: there is no mode to choose.  Five things can be given,
# each one or not (None): the RX1 band and the RX2 band (Dual_RX1 / RX2_Parameters.py), the bore
# (INNER_EDGE_RADIUS_MM), the outline (OUTER_EDGE_RADIUS_MM) and the gap (TRACK_GAP_MM).  Of the 32 combinations,
# 26 build, by four rules:
#   the gap   TRACK_GAP_MM, or the larger of the two sets' MIN_CLEARANCE_MM when it is None.  A band the generator
#             places sits exactly that far from the other set; with both bands given, the gap must be at least that
#   a band    one band given: the other is placed across the gap (RX2 outwards, RX1 inwards).  It runs to the board
#             edge on its side when that edge is given, and is as wide as the given band when it is not
#   an edge   not given: from the band, as in the Single Coil Set Generator.  Given: used as given, and checked
#   no band   needs both edges: the two bands share what is left between them by BAND_SPLIT
# The 6 combinations with no band and at most one edge leave nothing to size a band from; the checker says what to
# give.  The record file prints which combination was used and every radius; the wiki page Dual Layout shows all 32.

INNER_EDGE_RADIUS_MM  = 5.0         # the centre hole.  Must sit INNER_EDGE_INSET_MM inside the RX1 band.
OUTER_EDGE_RADIUS_MM  = 20.0        # the board edge.  Must leave OUTER_EDGE_OFFSET_MM past the RX2 band, and
                                    # OUTER_EDGE_TAIL_MARGIN_MM past the TX2 ring.
INNER_EDGE_INSET_MM   = 1.2         # bore = RX1 band start - this (the RX1 inner-tip vias sit on the band start)
OUTER_EDGE_OFFSET_MM  = 2.0         # outline = RX2 band end + this, at least
OUTER_EDGE_TAIL_MARGIN_MM = 0.7     # outline = TX2 tail end (one pitch outside the last turn, plus
                                    # TX_TAIL_EXTRA_MM) + this, at least; and set 2's fingers + this
EDGE_LINE_WIDTH_MM    = 0.05

# TRACK_GAP_MM = the copper-free ring between the two sets: from the outermost copper of set 1 (its TX ring and
# tail, or its RX fingers and the go-around brackets, whichever reach farther) to the innermost copper of set 2
# (the RX2 band start minus half an RX trace or a via radius, whichever is larger).  These reaches come from the
# Single Coil Set Generator's own formulas and are verified on the built copper.
#   A number: a band the generator places sits exactly this far from the other set; when you give both bands, the
#   gap between them must be at least this.  None: the same with MIN_CLEARANCE_MM (the larger of the two sets'
#   values) in its place.
#   What the gap does NOT do: it is not what isolates the two sets.  A balanced RX band sees no net flux from a
#   round TX ring, however close; the residual TX1 -> RX2 coupling comes from asymmetry (the exits, the vias,
#   layer misregistration) and falls only slowly with distance (dual boards in practice leave 1.1 ... 1.4 mm
#   between the two RX bands, all of it TX turns).  Keep the gap for the copper clearance and the solder mask; what keeps the fine track clean is the
#   distance from ring 1 of the rotor to the RX2 band (ROTOR_1_TO_RX2_MM below).
TRACK_GAP_MM = 0.5

# LAYOUT_TOLERANCE_MM = the generator's rounding allowance: the built copper may differ from the layout formulas
# above by this much before the run warns (the Single Coil Set Generator rounds its radii), and the outline gets this
# much extra room when ring 2 of the rotor covers the TX2 turns (so the disc's edge clearance is never a hair
# short; when half the edge line plus the ring's polygon vertices need more than this, they get it).  0.05 is
# enough for every board tried; 0 = no allowance.
LAYOUT_TOLERANCE_MM = 0.05

# BAND_SPLIT (read only when no band is given) = set 1's share of the free radial width: 0.5 = equal RX band
# widths (a 1x/16x board is usually near 0.5, a 1x/32x board near 0.35: the fine track gets the width).
BAND_SPLIT = 0.5


# =============================================================================
# TX TERMINALS
# =============================================================================
# Each set is turned on its own so that its TX ends end up at this angle (on a series TX without a tail, the
# default, the two ends sit one pitch outside the last turn, on TX_LAYER_A and TX_LAYER_B; a tail,
# TX_TAIL_EXTRA_MM, runs them farther out).  Different angles keep the two sets' breakouts apart.  The RX
# pattern's zero of each set lands wherever the turn puts it; the record file prints both.  Angles run from
# the +x axis of the page towards +y (down the KiCad page), like every other angle of the generators:
# 0 = the right, 90 = the bottom of the page, 180 = the left, 270 = the top.
TERMINAL_1_DEG = 180.0              # set 1 (inner)
TERMINAL_2_DEG = 0.0                # set 2 (outer)

# The two TX oscillators run free at their own EXCITATION_FREQ_HZ (Dual_TX1 / TX2).  Two free-running carriers
# over one coil area are unproven: two-IC dual boards usually drive ONE tank and set the second IC's TX current
# to zero, or couple the two tanks so that they lock to one frequency and phase.  If the two tanks here are
# driven separately, the IC's switching demodulator mixes the other carrier down to |f2 - n*f1|, and the AGC
# sees both carriers, so:
#   - the two frequencies must differ by at least TX_FREQ_SEPARATION_MIN of the lower one (0.2 = 20 %, the
#     usual rule for neighbouring LC sensors; closer is a warning), and
#   - they must not sit on a small integer ratio (3.0 / 4.5 MHz = 2:3 puts the 2nd harmonic of TX2 onto the
#     3rd harmonic of IC1's demodulator; 3.0 / 4.3 MHz does not): a ratio within TX_FREQ_RATIO_TOLERANCE of
#     any p:q with p, q <= TX_FREQ_RATIO_MAX_ORDER is a warning (0.02 = 2 %; the order 4 covers 2:1, 3:1, 4:1,
#     3:2, 4:3).  TX_FREQ_RATIO_MAX_ORDER = 1 turns the ratio warning off.
# Pulling the two tanks onto each other (injection locking) is not the risk: the lock range is about
# f0 * k / (2 Q), a few tens of kHz for coupling k < 0.3, nowhere near 1 MHz.
TX_FREQ_SEPARATION_MIN   = 0.2
TX_FREQ_RATIO_MAX_ORDER  = 4
TX_FREQ_RATIO_TOLERANCE  = 0.02

ROTOR_START_ANGLE_ZERO = "rx_zero"
ROTOR_CUSTOM_OUTLINE_RADIUS_MM  = 26.875 # custom: outer edge of the disc (None = no outline); the values here are what

########## Dual_SilkScreenSuggestion_Parameters.py #####################
"""
Dual_SilkScreenSuggestion_Parameters.py  -  the silkscreen suggestion for cutting the leads: where to break each
RX coil and where the two ends of each TX ring get their vias.

The generator's coils have no terminals: every RX coil (SIN and COS of each set) is one closed loop, and the two
ends of each series TX ring lie on top of each other (the Top end and the Inner 2 end at the same point).  The
user breaks each RX loop at one place and sets a via at each side of the cut, and extends each TX end to a via of
its own, then routes from those vias to the IC on the bottom layer.  This last step of the generation
(Dual_LeadCutting_SilkscreenSuggestion.py, run after the stator file is written) looks for a spot on each coil
where the vias have room on every layer and draws the suggestion on the silkscreen of the finished stator file:

    RX coil   a dashed box around the break, a dot at each of the two via sites, the name of each lead
              (SIN1_1, SIN1_2, COS1_1, ... for set 1; SIN2_1, ... for set 2)
    TX ring   a dot at each of the two via sites beside the stacked end, a dashed line from the end to each site,
              the name of each lead (TX1_1 = the Top end, TX1_2 = the Inner 2 end; TX2_1, TX2_2 for set 2)

It changes no copper: the marks are drawings on F.SilkS and B.SilkS (the bottom text mirrored), and the
coordinates are printed in the run and appended to Parameters.txt.  Nothing in this file changes a coil.

Units: mm unless the name says otherwise.  Nothing in this file is computed - edit values only.
"""

# =============================================================================
# THE SUGGESTION
# =============================================================================
SILKSCREEN_SUGGESTION = True        # False: the stator file is left as the assembler wrote it (no silkscreen)
SILKSCREEN_SIDES      = "both"      # "both": F.SilkS and B.SilkS;  "top": F.SilkS only;  "bottom": B.SilkS only

# Colour of every mark (lines, boxes, dots and the lettering), as a hex RGB string ("#RRGGBB").  KiCad keeps a
# colour per graphic item (it is written into each item's stroke); the fab prints the silkscreen in its own ink
# regardless.
SILKSCREEN_COLOR      = "#FFFFFF"

SILKSCREEN_LABELS     = True        # True: write the lead names (SIN1_1, SIN1_2, TX1_1, TX1_2, ...) next to the via sites
SILKSCREEN_DOT_ON_ALL_VIAS = False  # True: also a dot on every via the generator placed (both sides);  False: only
                                    # the via sites of the suggestion

# =============================================================================
# GEOMETRY OF THE MARKS
# =============================================================================
SILKSCREEN_LINE_WIDTH_MM  = 0.12    # line width of the boxes, lines and dot outlines
# The lead names are drawn with the repository's own stroke font (Generators/resources/SilkscreenFont.py, next to the
# generators: capitals, digits, a few signs; no KiCad font), as lines on the silkscreen, each name placed where it
# covers no other mark, name or via.
SILKSCREEN_TEXT_SIZE_MM   = 0.5     # height of a capital (mm); a glyph is 2/3 as wide, the letter pitch 5/6 of the height
SILKSCREEN_TEXT_STROKE_MM = 0.1     # line width of the lettering.  Most fabs print silkscreen lines down to about
                                    # 0.1 ... 0.15 mm and text down to about 0.8 mm height; smaller may come out unreadable
SILKSCREEN_DOT_RADIUS_MM  = 0.16    # radius of the filled dot at a via site
SILKSCREEN_BOX_MARGIN_MM  = 0.5     # the dashed box around an RX break reaches this far past the two via sites

# =============================================================================
# WHERE THE BREAK GOES  (the search; the result is printed in the run and in Parameters.txt)
# =============================================================================
# The two vias of an RX break sit on the coil this far apart (centre to centre, along the trace); the trace between
# them is what the user cuts.  At least VIA_DIAMETER_MM + MIN_CLEARANCE_MM.
SILKSCREEN_BREAK_VIA_GAP_MM   = 1.2
# The break is looked for on the coil's traces within this many degrees of the set's terminal angle
# (TERMINAL_1_DEG / TERMINAL_2_DEG in Dual_Board_Parameters.py), where the TX ends are, so that all leads of a set
# come together.  Larger = more candidates, further from the TX ends.
SILKSCREEN_SEARCH_SPAN_DEG    = 30.0
# The two breaks of a set and its TX end stay at least this far apart (centre to centre), so that the marks and
# the lead names do not land on each other.
SILKSCREEN_BREAK_SEPARATION_MM = 4.0
# The coil layers tried for the break, in this order; the first layer with a spot that has room is used.  On a
# 2-layer board (PCB_LAYERS = 2) the RX coils run on Top and Bottom: ["F.Cu", "B.Cu"].
SILKSCREEN_BREAK_LAYERS       = ["F.Cu", "In1.Cu"]
# A via of the suggestion keeps MIN_CLEARANCE_MM (Dual_Board_Parameters.py, or the larger one a set sets for itself)
# from every copper on every layer, and this much from the bore and the outline.
SILKSCREEN_VIA_EDGE_CLEARANCE_MM = 0.25
# The two via sites of a TX end are looked for up to this far from the stacked end (mm).
SILKSCREEN_TX_SITE_REACH_MM   = 2.0
