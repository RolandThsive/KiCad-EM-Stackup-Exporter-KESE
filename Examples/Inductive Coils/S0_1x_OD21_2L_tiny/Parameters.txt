"""
RX_Parameters.py  -  receiver (RX) coils: the SIN and COS coils of the stator.

Units: millimetres, degrees.  Nothing in this file is computed - edit values only.

# =============================================================================
# SIZE AND PERIODICITY
# =============================================================================
# LOOPS = number of electrical periods (sine waves) per mechanical turn (1 ... 16).
#   - It is also the number of metal sectors the rotor must have.
#   - Unique absolute range of the sensor = 360 / LOOPS degrees.
#   - 1 loop gives true 0-360 deg absolute output; higher counts give
#     proportionally finer angular resolution/accuracy per degree.
#   (1 loop = 1 full sine period = 2 lobes: one positive and one negative.)
LOOPS = 1   

# Radial band occupied by the RX copper (centre line of the traces): the RX coils swing between
# its inside and outside radius.  Give it in ONE of two ways (the other pair = None):
#
#   INSIDE_RADIUS_MM / OUTSIDE_RADIUS_MM : the two radii of the band
#   RX_R_BASE_MM / RX_A_MM               : its centre (r_base) and how far the coils swing in and out
#                                          from it (A): band = RX_R_BASE_MM - RX_A_MM ... RX_R_BASE_MM + RX_A_MM
#                                          e.g. 18.8 / 2.6 = a 16.2 ... 21.4 mm band.  Signal grows about
#                                          with r_base x A (the band area); a wider band spreads over a less
#                                          uniform TX field (see RX_PROFILE)
#
# Each pair goes together (both numbers or both None).  Both pairs None: the band is fitted to the
# board edges (INNER_EDGE_RADIUS_MM and OUTER_EDGE_RADIUS_MM, Board_Parameters.py, must then be set).
# With the band given, a board edge that is None is calculated from it; a board edge that is set is
# used as given (it must leave the usual margins - the checker says how much is needed).

OUTSIDE_RADIUS_MM = None
RX_R_BASE_MM      = None
RX_A_MM           = None

# (cosine, +/-) form the other.

# =============================================================================
# SHAPE OF THE RX BOUNDARY  r(angle)
# =============================================================================
#   "equal_area"         r^2 = mean(r^2) + amp * sin(...)   (the default)
#                        The flux weight of a single curve is an exact sine for a
#                        uniform field.
#   "cosine_r"           r = mean(r) + amp * sin(...)       (a limacon).  For an
#                        antiphase pair (which is what every coil here is) the flux
#                        weight is also an exact sine for a uniform field.

# Polyline resolution of one electrical period.
#   "auto"  -> smallest multiple of 8 whose chord error is <= RX_CHORD_TOLERANCE_MM
#   integer -> fixed value (a multiple of 8 from 48 to 4096).
# RX_CHORD_TOLERANCE_MM = how far a straight chord may lie from the true curve: 0.001 mm = 1 micron, which is
#   also the smallest value allowed (finer only adds points, not accuracy: the generator stops at 1024 chords
#   per loop and warns if that is not enough).  (The TX coil and the rotor have their own:
#   TX_CHORD_TOLERANCE_MM in TX_Parameters.py, ROTOR_CHORD_TOLERANCE_MM in Rotor_Parameters.py.)
STEPS_PER_LOOP         = "auto"
RX_CHORD_TOLERANCE_MM  = 0.001


# =============================================================================
# SUB-COILS  (distributed winding)
# =============================================================================
# Every RX coil (SIN and COS) is built from RX_SUBCOILS sub-coils.  A sub-coil is
# one antiphase pair of curves - exactly what a single coil is today.  The
# sub-coils of one coil are spread RX_SUBCOIL_SPLIT_ELEC_DEG apart (electrical
# degrees: one loop = 360) and wired in series, so each coil still is ONE closed
# series loop that you break out where you like.
#
#   RX_SUBCOILS = 1 : today's layout (the split is ignored)
#   RX_SUBCOILS = 2 : 2 sub-coils per coil (use split = 45)
#   RX_SUBCOILS = 3 : three sub-coils, centred on the coil axis (use split = 30, which spaces the curves
#                     evenly; 45 puts two curves on top of each other.  Crowded: needs a wide RX band
#                     or small vias; watch the clearance warnings)
#
# Effect of a split d between two sub-coils (relative to ONE sub-coil):
#     signal      x 2*cos(d/2)            (d = 45 -> 1.85x)
#     harmonic h  x 2*cos(h*d/2)          (d = 45 -> 3rd and 5th down ~59 %,
#                                          d = 60 -> 3rd removed,  d = 36 -> 5th removed)
# The split is rounded to a whole even number of polyline nodes (with STEPS_PER_LOOP =
# "auto" the resolution is chosen so that the requested value is reproduced; the summary
# prints the value actually used).
# Geometry limits: with 2 sub-coils the curve tips of the SIN and COS coils are spaced
# split and (90 - split) apart, so 45 is the uniform, roomiest choice; much above 50 or below
# 35 crowds the tip vias.  Whether the junction vias of the sub-coils fit depends on the
# circumference per loop: the checker estimates it and warns, and the generator stops with a
# message when they do not fit (then widen the RX band, use fewer loops or 1 sub-coil).
RX_SUBCOILS               = 1
RX_SUBCOIL_SPLIT_ELEC_DEG = 45.0


# =============================================================================
# LAYERS  (which copper layers carry the RX coils)
# =============================================================================
# PCB_LAYERS = 2 (Board_Parameters.py): Top and Bottom are used;
#                RX_RISING_EDGE_LAYER chooses which one carries the rising edges.
# PCB_LAYERS = 4: RX_LAYER_A / RX_LAYER_B name the two layers
#         1 = Top (F.Cu)   2 = Inner 1 (In1.Cu)   3 = Inner 2 (In2.Cu)   4 = Bottom (B.Cu)
#   They must differ.  Typical choice: 1 and 2 (Top + Inner 1), which sit closest
#   together in a standard 4-layer stack-up.  A carries the rising edges, B the
#   falling edges.
RX_LAYER_A = 1
RX_LAYER_B = 2
RX_RISING_EDGE_LAYER  = "F.Cu"      # 2-layer boards only: "F.Cu" or "B.Cu"

# Layer scheme.  Every phase carries its RISING edges (radius growing with
# angle) on one layer and its FALLING edges on the other, so that at every
# azimuth the two strands of a coil sit on opposite layers (equal air-gap
# exposure for sine and cosine, no layer-induced gain/harmonic mismatch).
# The layer swap (via) happens near the outer and inner tip of every lobe:
# RX_VIA_ELECTRICAL_DEG is the electrical angle of the outer-tip via
# (90 = exactly on the tip; the check accepts 50 ... 130).  Away from 90 the vias come
# close to the neighbouring curves: with the example band about 58 ... 122 builds
# cleanly for LOOPS 1 ... 4, less with more loops (LOOPS 16: about 80 ... 100).  A
# value outside 45 + 720 / STEPS_PER_LOOP ... 135 - 720 / STEPS_PER_LOOP is moved
# inside it, with a warning.
# With RX_SUBCOILS = 2 the via that joins the sub-coils needs it near 90: at most about
# 57 + split / 2 ... 123 - split / 2 (80 ... 100 for a split of 45).  A large split may fit
# at no angle at all: with the example band, 0.8 mm vias and 0.2 mm traces and clearance
# the limit is a split of about 47 (a wider band or smaller vias allow more).
RX_VIA_ELECTRICAL_DEG = 90.0


# =============================================================================
# BRIDGING FINGERS
# =============================================================================
# At the outer tip of every lobe of every phase the trace leaves the RX band
# radially, crosses OVER the TX turns and comes back, so the RX coils can be broken
# out outside the TX ring.  The finger sits on the RX layer nearest the top that is
# not a TX layer.  No terminals are created: the coils are broken out by hand.
#   "all"    = a finger at every outer tip of every phase
#   "single" = one finger per RX coil (one for sin, one for cos), on two neighbouring
#              outer tips (the sin+ tip of the first loop and the cos tip after it): the
#              coils are broken out side by side, and the TX terminal settles as close to
#              them as the clearances allow (TX_Parameters.py, "where the TX terminal goes")
#   "none"   = plain RX band, no fingers
# In a model "single" was as accurate as "none" and, untuned, more accurate than "all" from
# 4 loops up (the many fingers distort the coil shape); once the rotor is tuned for each,
# the three are within about 20 %.
RX_TABS           = "none"
# RX_TAB_LAYER = layer of the fingers: "auto" = the RX layer nearest the top that carries
# no TX turn - or, when both RX layers carry TX turns (e.g. a series TX on
# [1, 4]), the RX layer nearest the top - or 1 (Top), 2 (Inner 1), 3 (Inner 2), 4 (Bottom).
# On a layer with TX turns the TX makes way for every finger (go-around or stitched,
# TX_Parameters.py).
RX_TAB_LAYER      = "auto"
RX_TAB_LENGTH_MM  = 3.0     # finger reaches OUTSIDE_RADIUS + this (r = 24.4 mm on the example
                            # board).  It must clear the outermost TX turn (and, when the TX goes
                            # around the fingers, the outermost bracket): the checks say how long
RX_TAB_WIDTH_MM   = 1.0     # spacing of the two finger legs (snapped to polyline nodes).
                            # The finger adds a small flux sliver to the coil; a narrower
                            # finger disturbs the sin/cos signal less (matters most at
                            # high LOOPS). Keep >= about 0.6 for etching.

########## TX_Parameters.py ############################################
"""
TX_Parameters.py  -  transmitter (TX) coil: concentric turns outside the RX band.

Units: millimetres, degrees.  Nothing in this file is computed - edit values only.
Layers are numbered 1 = Top, 2 = Inner 1, 3 = Inner 2, 4 = Bottom (a 2-layer board has 1 and 4).
"""

TX_NET             = "TX"

TX_TURNS           = 1   # complete turns PER TX LAYER
TX_OFFSET_MM       = 1.1            # first turn radius = RX outside radius + this
TX_PITCH_MM        = 0.6            # radial pitch between turns
TX_TRACE_WIDTH_MM  = 0.2
# Points per TX turn (every turn is a polyline):
#   TX_STEPS = "auto" : as many as TX_CHORD_TOLERANCE_MM needs on the outermost turn (a multiple of 8, at least 48)
#   TX_STEPS = number : that many (12 ... 20000).
# TX_CHORD_TOLERANCE_MM = how far a straight chord of a TX turn may lie from the true circle: 0.001 mm = 1 micron,
#   also the smallest value allowed.
TX_STEPS           = "auto"
TX_CHORD_TOLERANCE_MM = 0.001
TX_TAIL_EXTRA_MM   = 2.0            # radial tail that carries the TX terminal
# TX_SHAPE = shape of the turns (any letter case):
#   "stepped_diagonal" : concentric circles joined by short straight steps just before the TX terminal, at
#                        TX_STEPPED_ANGLE_DEG.
#   "stepped_arc"      : concentric circles joined by arcs centred on the TX terminal via.  The via sits on
#                        the first turn; arc n (radius
#                        TX_STEPPED_ARC_RADIUS_MM + n x TX_PITCH_MM) leaves turn n on one side of the via, runs
#                        round it and lands on turn n + 1 on the other side, with sharp corners.  The arcs are one
#                        pitch apart, so the copper gap between them is the same as between the turns, and the
#                        outer tail leaves from the outermost point of the last arc.  TX_STEPPED_ANGLE_DEG and
#                        TX_INSIDE_VIA_DISTANCE_MM are not used.
#   "spiral"           : one smooth Archimedean spiral, the gap between turns equals the pitch
#                        everywhere.  Use it when TX_PITCH_MM is tight (pitch - trace width close
#                        to the clearance), e.g. a 0.4 mm pitch.  Its last turn
#                        ends one pitch farther out, and the fingers must reach past it (RX_TAB_LENGTH_MM
#                        at least 3.5 with the values in these files).
TX_SHAPE           = "stepped_diagonal"
# TX_STEPPED_ARC_RADIUS_MM = radius of the innermost arc of a "stepped_arc" TX (mm, measured from the centre of the
#   terminal via); the other arcs follow at TX_PITCH_MM.
#     "auto" : the smallest radius that keeps MIN_CLEARANCE_MM from the via (via radius + half a TX trace +
#              clearance) and is larger than TX_PITCH_MM (each arc must reach the next turn), plus 0.02 mm:
#              0.72 mm with the defaults.
#     number : that radius; it must be larger than TX_PITCH_MM and smaller than TX_PITCH_MM + TX_TAIL_EXTRA_MM.
#   Only used by "stepped_arc".
TX_STEPPED_ARC_RADIUS_MM = "auto"
# TX_STEPPED_ANGLE_DEG = the angle of the steps of a "stepped_diagonal" TX (where each turn steps out to the next one,
#   just before the TX terminal), measured from the turn: 90 = straight out (radial), 45 = diagonal, smaller =
#   a longer, gentler slope.  Each step is one straight piece, and the run down to the terminal via
#   (TX_INSIDE_VIA_DISTANCE_MM) takes the same angle.
#     5 ... 90 : the angle.  Neighbouring steps are parallel, so their copper gap is
#              TX_PITCH_MM * cos(angle) - TX_TRACE_WIDTH_MM; at steep angles (above about 45 deg with the
#              defaults) that is less than MIN_CLEARANCE_MM, and each step then starts a little before the one
#              inside it to keep the clearance.  The generator prints the gap it got.
#   Only used by "stepped_diagonal" (a "stepped_arc" TX has arcs, a "spiral" TX no steps).
TX_STEPPED_ANGLE_DEG = 45
# TX_INSIDE_VIA_DISTANCE_MM = where the via at the TX terminal sits (the via that joins the inner tail
#   to the first turn, or the two spirals of a series TX).  0 = on the trace ends - only one pitch from the
#   next turn, which with a 0.8 mm via and a 0.6 mm pitch is closer than MIN_CLEARANCE_MM.  A positive value moves it that far towards the centre (a negative one: away from
#   it); every turn that starts at the terminal then leaves its circle a little earlier and runs down to
#   the via at the slope of the TX's own steps (TX_STEPPED_ANGLE_DEG for "stepped_diagonal"; 45 deg for "spiral"),
#   with a short flat piece into the via.  Keep it below
#   TX_OFFSET_MM - via radius - half an RX trace - MIN_CLEARANCE_MM (0.4 mm with the defaults), or the
#   via comes too close to the RX coils.  The generator measures it and warns.
#   Not used by "stepped_arc" (its via always sits on the first turn, at the centre of the arcs).
TX_INSIDE_VIA_DISTANCE_MM = 0.3
# Where the TX terminal goes: there is no setting.  The TX looks for the place around the ring where its
# terminal (tail, via, steps or arcs, windows) keeps the largest gap from the RX copper (vias, curves,
# fingers, junction vias); with RX_TABS = "single" it takes the place nearest the two fingers that keeps
# MIN_CLEARANCE_MM.  The whole board is then turned so that the terminal ends up at 0 deg (the right,
# on the horizontal axis).  The angle it was turned by is printed and written into Parameters.txt.

# =============================================================================
# TX LAYERS
# =============================================================================
# TX_WIRING = how many layers carry TX turns and how they are joined (any letter case):
#   "single"   : TX_TURNS turns on TX_LAYER_A (TX_LAYER_B is not used); the inner tail runs on the
#                underpass layer (TX_SERIES_UNDERPASS_LAYER).
#   "series"   : TX_TURNS turns on TX_LAYER_A and TX_TURNS turns on TX_LAYER_B in series - two spirals
#                joined by one via at the inner end (2 x TX_TURNS turns; both run the same way round,
#                so their fields add).  Both terminals leave radially at the terminal.  TX_LAYER_A
#                is the spiral that runs inwards from the terminal, TX_LAYER_B the one that runs back out.
#   "parallel" : the same turns on TX_LAYER_A and TX_LAYER_B in parallel, stitched together through
#                vias around the TX terminal: about 6 % more receiver signal than the Top layer alone
#                and about 1.2 - 1.6x the Q in the model (about 0.6x the resistance, but also a lower
#                inductance; more on thin boards and with the staggered break style).  Put TX_LAYER_A on
#                the Top layer.
# TX_LAYER_A / TX_LAYER_B : 1 = Top, 2 = Inner 1, 3 = Inner 2, 4 = Bottom (a 2-layer board has 1
#   and 4); they must differ.  Examples:
#     TX_WIRING = "single", TX_LAYER_A = 4                  : on the Bottom layer, the inner tail on the
#                                                             Top layer (the default)
#     TX_WIRING = "single", TX_LAYER_A = 1                  : on the Top layer, next to the rotor: about
#                                                             15 % (0.8 mm board) to 30 % (1.6 mm board)
#                                                             more receiver signal per TX volt in the model
#     TX_WIRING = "series", TX_LAYER_A = 1, TX_LAYER_B = 4  : the fingers run on the Top layer and the
#                                                             Top turns go around them
#     TX_WIRING = "series", TX_LAYER_A = 1, TX_LAYER_B = 3  : a 4-layer board with the RX on layers 1
#                                                             and 2
#
# Where an RX bridging finger (RX_TAB_LAYER, RX_Parameters.py) runs on a layer that carries
# TX turns, the TX makes way for it:
#   "staggered" (go-around): every turn ends a little before the finger - the outer turns farther
#        away than the inner ones, a staircase - and runs straight out, parallel to the finger, to a
#        via just outside the TX ring.  On another layer a bracket (the innermost turn on the innermost
#        bracket) carries it around the end of the finger to the matching via on the other side.  The
#        fingers must reach past the outermost bracket (about 2 mm longer with the defaults; the checker
#        gives the minimum RX_TAB_LENGTH_MM), which can push the outer board edge out.
#   "stitched" (parallel TX only): the turns on the finger's layer stop at a via on each side
#        of the finger and the turns of the other layer carry the current past it.
# All TX turns are one net, so KiCad's DRC cannot see a via touching another turn: the
# generator checks that itself and warns.
TX_WIRING  = "series"
TX_LAYER_A = 4
TX_LAYER_B = 1

# ---- SERIES block (TX_WIRING = "single" or "series") ---------------------------------------
# A series TX always makes way for the fingers with "staggered" (go-around).
# TX_SERIES_UNDERPASS_LAYER = "auto" or a layer number:
#   "single" : the layer of the inner tail and of the go-around brackets.  "auto": Top for a
#              Bottom TX, Bottom (2-layer) or Inner 1 (4-layer) for a Top TX.
#   "series" : the layer of the go-around brackets.  "auto": the other TX layer, outside its turns.
TX_SERIES_UNDERPASS_LAYER = "auto"

# ---- PARALLEL block (TX_WIRING = "parallel") -----------------------------------------------
# TX_PARALLEL_BREAK_STYLE = how the turns make way for a finger on one of the two layers:
#   "stitched"  : the turns on the finger's layer stop at a via on each side of the finger; the
#                 other layer carries the current past it (no copper outside the TX ring).
#   "staggered" : the turns on the finger's layer go around the finger (go-around), with the
#                 brackets on the other TX layer outside its turns; both layers stay complete.
TX_PARALLEL_BREAK_STYLE = "stitched"

Rotor_Parameters.py  -  the rotor (the metal "target") made by RotorBuilder.py.

Units: millimetres, degrees.  Nothing in this file is computed - edit values only.

# "according_to_stator" : everything below ROTOR_AUTO_* is applied on top of

#                         extent from the RX band and the TX ring, ...).

ROTOR_MODE = "according_to_stator"

# ---- according_to_stator ----------------------------------------------------
ROTOR_AUTO_DUTY             = 0.5   # metal fraction of each period (0.5 = 180 deg electrical).  A
                                    # copper pattern of fraction k/h has no h-th harmonic (1/3: no
                                    # 3rd), but the field it leaves has: the eddy currents crowd the
                                    # field at the copper edges, which moves the fraction that removes
                                    # the 3rd harmonic of the field above 1/3 and changes the signal.
                                    # The best value for a coil needs a model of the eddy currents
                                    # or a test rotor.
ROTOR_AUTO_START_ANGLE_DEG  = 0.0   # mechanical angle of the first sector edge

# ---- outer edge of the copper: over the TX turns (default) -----------------

# of the outermost TX turn.  Every sector is a shorted turn
# driven by the TX flux it encloses, and that flux is densest right beside the TX conductors: in
# an eddy-current model that gave 5-8 % more receiver signal than ending the copper inside the
# TX ring; most of the gain is reached 0.5 mm past the outer turn.  Whether it also lowers the
# angle error depends on the coil (in the model it did for 1 loop and not for 16).

                                    # ROTOR_AUTO_EDGE_CLEARANCE_MM inside the board outline.

# negative = stops short of it.  None = not set (see each line).  The copper always stays
# ROTOR_AUTO_EDGE_CLEARANCE_MM away from the bore (and, with ROTOR_AUTO_COVER_TX = False,

ROTOR_AUTO_EXTENSION_MM       = None  # both edges (the outer one only with ROTOR_AUTO_COVER_TX = False).
                                      # None = AIR_GAP_MM
ROTOR_AUTO_EXTENSION_INNER_MM = None  # inner edge only.  None = ROTOR_AUTO_EXTENSION_MM.
                                      # Not critical; the bore limits it.
ROTOR_AUTO_EXTENSION_OUTER_MM = None  # outer edge only, used only with ROTOR_AUTO_COVER_TX = False.
                                      # None = ROTOR_AUTO_EXTENSION_MM.

ROTOR_AUTO_TX_CLEARANCE_MM  = 0.1   # ROTOR_AUTO_COVER_TX = False only: copper stays this far inside the TX ring
ROTOR_AUTO_EDGE_CLEARANCE_MM = 0.5  # rotor copper stays this far from the bore edge and from the outline

ROTOR_PCB_THICKNESS_MM = None   # thickness of the rotor board written into the KiCad file (mm); None = the

#   ROTOR_ARC_STEPS_PER_SECTOR = "auto" : as many as ROTOR_CHORD_TOLERANCE_MM needs (at least 8)

########## SilkScreenSuggestion_Parameters.py ##########################
"""
SilkScreenSuggestion_Parameters.py  -  the silkscreen suggestion for cutting the leads: where to break each RX
coil and where the two ends of the TX coil get their vias.

The generator's coils have no terminals: every RX coil (SIN and COS) is one closed loop, and the two ends of the
TX coil lie on top of each other at the end of its tail (one on each of its two layers).  The user breaks each
RX loop at one place and sets a via at each side of the cut, and extends each TX end to a via of its own, then
routes from those vias to the IC.  This last step of the generation (LeadCutting_SilkscreenSuggestion.py, run
after the stator file is written) looks for a spot on each coil
where the vias have room on every layer and draws the suggestion on the silkscreen of the finished stator file:

    RX coil   a dashed box around the break, a dot at each of the two via sites, the name of each lead
              (SIN_1, SIN_2, COS_1, COS_2)

              the name of each lead with its layer (TX_1 TOP, TX_2 BOT, ...)
