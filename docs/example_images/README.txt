Pictures of the three example boards of Generator/Input/, one folder per board: rf_module/,
hdi_module/ and pcie_card/. The main README shows some of them by their path in the repository;
the wiki's Examples page shows them by their raw URL on main
(https://raw.githubusercontent.com/RolandThsive/KiCad-EM-Stackup-Exporter-KESE/main/docs/example_images/<board>/<name>),
so they show in the wiki only after they are on main.

Each picture is the board's GLB drawn with three.js, saved as a lossless WebP; an animation is an
animated WebP. The name says what it shows, and from which mode where that matters:
top_visual.webp is the top of the visual-mode GLB, layers_apart_simulation.webp the
simulation-mode GLB with its layers drawn apart.
