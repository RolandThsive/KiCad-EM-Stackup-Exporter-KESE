# KESE Logo

**Kese_Square**: the Net K mark. The stem and the two arms of the K are three nets, each in its
own colour, joined at a copper node and ending in via pads, on solder-mask green.

**Kese_Rectangular**: the mark with the name and "KiCad EM Stackup Exporter". The text is drawn
as outlines, so the SVG looks the same without the fonts installed.

| File | Use |
|---|---|
| `Kese_Square.svg` | The square mark, any size |
| `Kese_Square_<px>.png` | 16, 32, 48, 64, 128, 256, 512 and 1024 px, transparent corners |
| `favicon.ico` | 16, 32, 48 and 64 px |
| `Kese_Rectangular.svg`, `Kese_Rectangular_<h>.png` | On its own dark panel; 80, 160, 320 and 640 px high |
| `Kese_Rectangular_Transparent.svg`, `Kese_Rectangular_Transparent_<h>.png` | Dark text, no background, for light pages |

Colours: solder mask `#1E5A2D`, copper `#CD803E`, nets `#D62728` and `#1F77B4`, stem `#e8e4d8`.
Lettering: Barlow Condensed ExtraBold and IBM Plex Mono (both SIL Open Font License).
