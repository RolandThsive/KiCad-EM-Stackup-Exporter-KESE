# Corpus Testing

KESE was run on 3,138 KiCad boards from 819 open hardware projects ([Credits](Credits.md)), six times each, one
file format a run, with the Verifier on. The pages of that test, a section for every board with its chart, live
apart from the code, on the
[`corpus-testing`](https://github.com/RolandThsive/KiCad-EM-Stackup-Exporter-KESE/blob/corpus-testing/docs/wiki/Corpus-Testing.md)
branch. In the wiki this page is that branch's index, with its pages after it: the wiki sync
(`.github/workflows/WikiSync.yml`) takes them from there.
