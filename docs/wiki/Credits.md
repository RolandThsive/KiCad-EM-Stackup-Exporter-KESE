# Credits

KESE was checked on 3,138 KiCad boards from 819 open hardware projects on GitHub. Thank you to
the authors and contributors of every one of them.

Every board belongs to its authors, and so does its license: the rights in each design, and the
terms it may be used under, are theirs alone. Their boards were used only for checking KESE and
verifying its determinism (that the same board and settings give the same files, byte for byte).
No board, nor any part of one, is included in KESE or distributed with it.

## The Licenses

The license is the one GitHub identifies in the repository (an SPDX identifier); where GitHub
names none, it is what the project's own license files or README say, with the file it is in.
"No license found" means that neither the repository's root, the folders of its boards nor its
README names one, and the boards remain under their authors' copyright. Each repository is the
authority on its own terms. The licenses were looked up on 8 November 2026.

The repository's
[`credits.txt`](https://github.com/RolandThsive/KiCad-EM-Stackup-Exporter-KESE/blob/corpus-testing/credits.txt)
holds the same list, with the path of each board in its repository.
