Pictures for the wiki (docs/wiki/) go here.

Name them <page prefix>_<number>_<short name>.png, for example copper_2_via_section.png or
mask_1_openings.png; an animation is an animated .webp, such as start_1_modes.webp. Every
picture is referenced from the wiki by its raw URL on main
(https://raw.githubusercontent.com/RolandThsive/KiCad-EM-Stackup-Exporter-KESE/main/docs/images/<name>),
so it shows in the wiki only after it is on main.

One colour per copper layer or per net everywhere, true-to-scale line widths, 200 dpi,
board or outline edges as thick black lines.
