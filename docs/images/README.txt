Pictures for the wiki (docs/wiki/) and the main README go here; pictures of the three example
boards are in docs/example_images/.

Name them <page prefix>_<number>_<short name>.webp, for example copper_2_via_section.webp,
mask_1_openings.webp or readme_1_feature_test_boards.webp. Every picture is a lossless WebP, and
an animation an animated WebP, such as start_1_simulation.webp. The wiki refers to its pictures
by their raw URL on main
(https://raw.githubusercontent.com/RolandThsive/KiCad-EM-Stackup-Exporter-KESE/main/docs/images/<name>),
so they show in the wiki only after they are on main. The main README refers to its pictures by
their path in the repository.

One colour per copper layer or per net everywhere, true-to-scale line widths, 200 dpi,
board or outline edges as thick black lines.
