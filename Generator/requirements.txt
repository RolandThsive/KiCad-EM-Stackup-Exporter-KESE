# (it has no wheel for Python 3.14; there 7.9.3.1.1 passes the STEP tests, about half as fast; 8.0 lacks two classes
# the tests use).  They skip that check without it, and KESE itself never needs it.
# The tests run under pytest (python -m pip install pytest), which KESE itself does not need either.
