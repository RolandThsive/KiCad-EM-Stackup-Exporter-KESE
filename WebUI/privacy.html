Privacy

In short: your board never leaves your computer. The exporter runs entirely in your browser. There are no accounts, no cookies, no analytics and no tracking, and nothing you load or make is sent to the project.

Your Board and Your Files

  • The .kicad_pcb you choose is read by your browser and processed there, by Python running inside the page. It is not uploaded anywhere.
  • While the tab is open, the files of the last run are kept in your browser's private storage on your own disk (the Origin Private File System), so big models do not fill the memory. They are deleted when you close or reload the tab (after a browser crash, on your next visit), and whenever you start a new run.
  • Parameter files you import are read in the browser the same way.

What the Browser Downloads, and From Whom

Like any website, the servers that deliver the page receive your IP address and the usual request details (browser, time, the file asked for). The page itself sends them nothing else.

  • GitHub Pages hosts the page. GitHub says that when a Pages site is visited, the visitor's IP address is logged and stored for security purposes. See GitHub Pages: data collection and the GitHub General Privacy Statement.
  • jsDelivr (cdn.jsdelivr.net), a public open-source CDN, delivers Python (Pyodide) and the 3D viewer (three.js), pinned to exact versions. If jsDelivr does not answer, the page uses an identical copy on GitHub Pages instead. See jsDelivr's privacy policy.
  • The fonts are served from this site: no request goes to Google Fonts.

Storage in Your Browser

Besides the run's files above, the page may set one session flag (kese-three-backup) when it had to switch to the backup copy, so a reload does not try jsDelivr again; it is gone when the tab closes. Your browser's normal cache keeps the downloaded files, so the next visit is faster. None of this is used to identify or follow you, and all of it is needed for the page to work.

Report a Problem

The page's Report a Problem link opens a new GitHub issue filled in with the page's build, your browser, the window size and the settings you changed. It never includes your board or its name. Nothing is sent until you read it and press GitHub's own submit button, and you can edit or delete any of it first. Issues on GitHub are public and follow GitHub's privacy statement.

In the Blog

When you use the exporter inside the blog (ro-h-bots.blogspot.com), the blog page around it is served by Blogger, a Google service, under the Google Privacy Policy. The exporter in its frame works exactly as described here.
